# 创谱静力水准检测系统

创谱静力水准产品介绍的优化版源码工程，采用原生 HTML、CSS 和 JavaScript，无第三方运行依赖。支持离线阅读、原理演示、测试资料切换、方案导出和打印。

## 运行

直接双击 `index.html`，并保持 `assets` 目录的位置不变。开发时也可以在本目录运行：

```sh
python3 -m http.server 8000
```

随后在本机浏览器访问 `http://localhost:8000`。

## 目录

```text
chuangpu-hls-codex/
├── index.html                  # 页面入口
├── assets/
│   ├── css/
│   │   ├── styles.css          # 基础样式与打印样式
│   │   └── refinements.css     # 优化样式与响应式适配
│   ├── js/
│   │   ├── script-01.js        # 图片资源映射
│   │   ├── script-02.js        # 原理、图库、方案与导出
│   │   └── enhancements.js     # 阅读进度与返回顶部
│   └── images/                # 产品、软件与测试图片
├── tools/build_offline.py      # 单文件离线版生成工具
├── AGENTS.md                  # 项目维护约定
└── 优化说明.md                 # 优化及验证记录
```

## 生成单文件离线版

需要 Python 3.9 或以上版本，无需安装依赖。在工程目录运行：

```sh
python3 tools/build_offline.py
```

生成 `dist/创谱静力水准检测系统_离线版.html`。图片、CSS、JavaScript 均嵌入 HTML，可单独复制和打开。`dist/` 是可重新生成的产物，默认不纳入 Git。

## 修改与维护

修改文案和布局请编辑 `index.html`；样式优先编辑 `assets/css/refinements.css`。脚本按入口文件中的顺序加载。

软件截图由 `assets/js/script-01.js` 中的 `software` 字段指定。替换时将图片保存到 `assets/images/`，修改该字段对应的相对路径，再重新生成离线版，图库与放大视图会使用同一图片。目前仍是原源码包中的软件截图；聊天中新展示的截图尚未作为原始文件导入。

保留 UTF-8 编码与本地相对路径。外部资料链接和邮件联系需网络或邮件程序。

## 验证记录

优化版本已通过 Chromium 下六种宽度（320、390、620、768、1024、1440px）及主要交互检查，包含原理演示、资料切换、方案实际下载、导航和打印调用。单文件版本也验证过断网图片切换。打印 PDF 已生成验证，未逐页人工验收纸张布局。

后续修改应检查浏览器控制台错误、手机横向溢出、图片放大、原理演示、方案导出和打印。构建脚本会校验引用的本地图片和文件是否存在。
