# 创谱科技-VUV质谱波长扫描软件 · C 原生版

版本 **3.0.0**，Windows 10 / 11 x64。程序以 **C11 + Win32 API + GDI** 编写，双击 EXE 直接打开桌面窗口。无需安装 Python、浏览器、WebView、Java 或 .NET，无本地网页服务，不需要联网。应用图标为电机与光谱曲线组合。

`Specreation_VUV_Scan_C.exe` 与中文文件名 EXE 内容相同。Windows 自带 UCRT 和系统 DLL 是基础依赖；真实设备仍需厂家驱动及相机 SDK2。

## 快速试用

1. 双击 EXE。“设备连接与独立控制”中默认选择模拟设备，分别点击“连接电机”和“连接相机”。模拟数据明确标记，不代表实测结果。
2. “相机参数与读取”设置曝光时间和平均帧数，点击“应用相机参数”或“采集并读取”。只连接相机也能采集；只连接电机也能独立运动。
3. “扫描初始化与采集”选择点扫描或连续扫描，填写计划、积分列和本机数据目录。点击“检查范围与采样周期”，再点击“① 扫描初始化”。初始化会移动到起点。
4. 初始化完成后点击“② 开始扫描”。下方显示位置—信号曲线、当前相机光谱和数据表。
5. “全部停止”终止后续动作并保留已保存数据；退出使用“安全退出”或窗口关闭按钮。低温真实相机会先关闭制冷并等待回温。

默认数据目录：`%LOCALAPPDATA%\Specreation\VUVScanC\scans`。设置保存在其上级目录的 `settings.json`；重新启动不自动连接真实设备，不自动执行运动。

## 真实设备连接

**Newport 转台 / SMC100CC：**安装串口或 USB 转串口驱动，填写 COM、控制器地址、波特率和流控。默认 SMC100CC、57600、8N1、XON/XOFF。按照已经确认可配套使用的硬件设置，确保控制器位置单位为角度。软件不改写转台类型、控制器配置或归零参数。

连接只查询设备，不自动归零。未建立参考位置时可显式“归零 / 回参考位”；该按钮会实际运动。独立控制包括绝对定位、正反向相对运动、运动速度和停止。步长指角度增量，不是电气脉冲数。

本机角度保护默认 ±5°，与控制器 SL/SR 软件限位取交集。默认值需按实际机构调整；SL/SR 是软件行程，不能当作机械限位。连接参数或本机保护修改后重新连接电机。

**Andor / Oxford Instruments Newton 940：**安装匹配完整型号、序列号和 Windows x64 的驱动及 SDK2。在界面选择厂家提供的 `atmcd64d.dll` 或适用 legacy DLL 的完整路径，相机索引单台通常为 0。SDK3 的 `atcore.dll` 不适用本接口。SDK 目录需能使用电脑当前 ANSI 编码，建议保留厂家的英文安装路径和配套文件。

软件动态加载厂家 DLL，不附带专有 SDK 或硬件驱动。关闭其他正在占用设备的软件。探测器宽高、读出选项和增益从 SDK 查询，不根据“Newton 940”硬编码尺寸。

真实 CCD 低于 0℃或温度无法确认时，软件保持 SDK 连接并等待安全回温。回温期间保持相机供电和连接，并遵循厂家冷却说明；电机仍可独立操作。软件停止不能代替设备实体停止措施。

## 相机参数与信号定义

支持曝光时间、每点平均帧数、FVB 全垂直合并 / Single Track 单轨 / Image 图像 ROI、横纵 bin、ADC、输出放大器、水平和垂直读出速度、前置增益、快门 TTL / 模式 / 延时、采集超时、目标温度和制冷。硬件不支持的组合会返回 SDK 错误。

- ROI 从 1 起，包含终点；终点 0 为全幅，尺寸须能被 bin 整除。单轨中心 0 自动取中间位置。
- 图像按输出行求和或取平均，再对同一点各帧求平均，得到一维光谱。积分信号是所选输出列的光谱之和，单位 count。
- 积分起止列从 0 起，止列 -1 为最后一列。像素轴为原始探测器列中心，bin 后可出现小数。
- 每帧原始 signed int32 数据均保存，不自动扣暗、不截断负值。实际曝光以 SDK 回读值为准。
- “采集并读取”应用当前参数并采集、保存；“导出当前光谱 CSV”使用原生文件对话框选择保存位置。

电机和相机可分别连接、断开及操作。独立相机采集不要求电机存在，未连接时位置留空，不编造位置值。

## 两种扫描

**点扫描：**设置起点、带符号步长、点数和停稳时间。点数包含起点，终点为 `起点 + (点数−1)×步长`。每点执行定位 → READY 与位置允差复核 → 停稳 → 每帧曝光前后位置复核 → 读取并保存。设置变更、独立运动、停止或重新连接后需重新初始化。

**连续扫描：**设置起点、带符号角速度、采样周期、点数和预运行时间。扫描过程中只发出一次指向保护终点的 PA 运动命令，按时间采集，相邻采样不停止电机；达到点数后停止，并尝试恢复原速度。

保护终点根据速度、点数、周期、曝光 / 读出与通信预算、停止余量计算。周期过短或超出行程时初始化拒绝。运行记录实际时间和延迟，处理超过一个完整周期时终止，避免静默跳点。

**连续扫描的位置是软件估计值。** 每帧读取曝光前和读出后的位置，在两者之间对主机估计的曝光中点做线性插值；多帧取平均，前后跨度同时保存。它不是硬件触发或编码器锁存；加减速、串口延迟和曝光运动会影响对应关系。要求更严格的位置对应时使用点扫描，或另行配置硬件同步。

单次最多 50000 点，单点最多平均 100 帧；实际数据量和可用周期取决于相机读出模式、通信与磁盘速度。连续计划时长限制为 24 小时。

## 波长标定

暂无实测标定时使用角度扫描。可在界面输入或导入一次至三次多项式 `λ(θ)=a0+a1θ+a2θ²+a3θ³`，单位 deg / nm，需给出严格单调的有效角度范围，禁止外推。JSON 示例见 `examples`；真实模板中的 null 必须替换成实测值，不能直接使用模拟系数。

点扫描可按波长步长反解角度。连续扫描起点可用波长输入，速度始终为 °/s，不保证等波长间隔。标定只定义选定参考像素的中心波长，不等于整幅 CCD 的逐像素 `λ(θ,p)` 标定。未应用标定时不显示虚构波长。

## 数据文件

每次采集自动创建独立文件夹，CSV 采用 UTF-8 BOM，可导入 Excel / Origin。

| 文件 | 内容 |
| --- | --- |
| `manifest.json` | 版本、设备来源、实际参数、扫描计划、标定、完成状态及提交点数 |
| `scan_points.csv` | 位置与目标、前后位置和跨度、估计模型、中心波长、积分信号、温度及时间 |
| `spectra.csv` | 每点完整的平均光谱，表头带像素中心坐标 |
| `raw/*.npy` | 每点每帧的二维 signed int32 原始数组，可由 NumPy 等读取 |
| `events.jsonl` | 定位、采集、前后位置时间、原始帧保存和逐点提交记录 |

已完成点与中断点的原始帧保留，不自动续扫。意外退出后以 `manifest.completed_points` 为完整提交边界；`partial_point` 标明尚未提交的帧，状态仍为 running 时应核查尾部数据。时间戳为 UTC，界面日志为电脑本地时间。

## C 源码构建

程序主体和设备驱动都是 `.c` 文件，未使用 C++ / Qt / C# / 网页封装。cJSON 直接编入 EXE；通知见 `THIRD_PARTY_NOTICES.txt`，也已嵌入 EXE 资源。

Windows 安装 x64 UCRT MinGW-w64 或 LLVM-MinGW C 工具链并加入 PATH，运行 `build_windows.cmd`。输出 `build\Specreation_VUV_Scan_C.exe`。Linux 交叉编译设置 `MINGW_PREFIX` 后运行 `bash build_linux.sh`，无需在终端安装开发环境才能使用成品。

源码结构：`core.c` 为坐标 / 扫描计算，`devices.c` 为 Win32 串口和 SDK2，`engine.c` 为扫描状态机与数据保存，`main.c` 为原生控件和 GDI 绘图，`platform.c` 为系统接口。`tests` 中的 Python 文件仅用于开发验证，不参与成品运行。
