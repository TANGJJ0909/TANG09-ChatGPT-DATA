# 创谱科技-VUV质谱波长扫描软件

版本 2.0.0，Windows 10 / 11，64 位。电机接口为 Newport SMC100 串口协议，相机接口为 Oxford Instruments / Andor Newton 的 SDK2。

## 1. 启动与退出

直接双击“创谱科技-VUV质谱波长扫描软件.exe”或英文下载文件 Specreation_VUV_Scan.exe。它们是同一个程序，无需安装 Python。首次自动准备内置运行环境，之后校验并复用缓存。建议用户盘至少保留 200 MB 空间，测量数据另需空间。界面在默认浏览器打开，资源和通信均在本机，可离线运行。

默认两台设备都不连接，模式预选为模拟。分别点击“连接电机”和“连接相机”即可试用。模拟数据不能用于实际仪器性能或波长判定。

关闭浏览器不会终止后台或运动。使用右上角“全部停止”中止当前操作，实验结束点击“安全退出”。低温 CCD 将先关闭制冷并监视回温，达到 0℃后关闭 SDK；回温期间保持供电和连接，并遵循相机硬件手册的冷却要求。温度无法确认时不会自动卸载 SDK。

## 2. 真实设备连接与断开

电机和相机分别选择模拟 / 真实模式，分别连接或断开。仅连接电机也能运动，仅连接相机也能采集。断开一个设备不会自动断开另一个。相机在回温断开期间，电机仍可独立操作。

真实电机：安装所需串口 / USB 转换驱动，输入 COM、控制器型号、地址、波特率、流控。本程序默认 SMC100CC、57600、8N1、XON/XOFF，应按实际设备调整。连接仅查询状态，不自动归零、复位或运动。控制器须已经由厂家正确配置转台、角度单位、速度范围及行程。

本机软件角度保护默认 ±5°，并与控制器 SL/SR 软件行程限位共同约束定位目标。默认值不是已确认的机械安全行程。SL/SR 不等同于机械硬限位；串口及保护配置在重新连接电机后生效。

真实相机：安装支持实际 Newton 940 完整型号与序列号的 Windows x64 相机驱动和 Andor SDK2。填入 atmcd64d.dll 或厂家要求的相应 legacy DLL 的完整路径，选择相机索引，单台通常为 0。SDK3 的 atcore.dll 不能替代 SDK2。联机时关闭 Solis 等其他占用设备的软件。

本包不包含厂家专有 SDK DLL 或硬件驱动，需从厂家获取。您此前确认可用的转台 / SMC100 配套仍按实际铭牌和厂家配置使用，软件不会改写控制器的电机类型配置。

## 3. 电机独立运动

“设备与独立控制”页面提供绝对定位、正 / 负相对运动、运动速度设置和归零 / 回参考位置，不启动扫描，也不要求连接相机。移动前检查角度范围、方向、光路、机械间隙和线缆余量。

归零会发出运动命令：未建立参考位置时执行控制器 OR；已 READY 时回到 0°。归零路径由控制器配置决定。软件中的角度步长是位置增量，不是电机电气微步或脉冲数量。修改电机位置或速度会使已有扫描初始化失效。

## 4. 相机设置与独立采集

可设置曝光时间（ms）、每点平均帧数、FVB / 单轨 / 图像模式、横纵 bin、ROI、图像行求和 / 平均、ADC、输出放大器、读出速度、前置增益、快门、采集超时及制冷。选项和真实探测器尺寸从 SDK 查询，硬件不支持的组合会返回错误。

图像 ROI 从 1 开始、包含终点，终点 0 表示全幅，尺寸应能被 bin 整除。单轨中心 0 表示自动取中间行。输出像素轴为原始探测器列中心，从 0 起，bin 后可为小数。

“应用相机参数”只应用参数；“采集并读取数据”会应用当前参数并采集指定帧数，保存每帧原始二维 int32 数组与平均后的一维光谱。没有电机时位置留空，有电机时记录前后位置。独立相机采集不要求位置固定，不应把移动中的数据误解为点扫描。

图像到光谱按输出行求和或平均，再对同一点各帧求平均。积分信号为选定输出列的平均光谱之和，单位 count；可修改积分起列和止列，止列 -1 表示末列。软件不自动扣暗、不截断负值，也不执行辐射定标或质荷比标定。

制冷需要显式操作，可要求温度稳定后再采集。实际曝光以 SDK 回读值为准。采集超时应大于曝光及读出周期。“导出当前光谱 CSV”将当前显示的像素与信号保存到本机浏览器下载目录；原始数据也已自动保存。

## 5. 扫描初始化

在“扫描采集”选择模式、坐标和参数后，点击“检查范围与数据量”，再点击“扫描初始化”。初始化要求两台设备均已连接、电机 READY，依次执行：

1. 应用相机参数，读取实际曝光 / 读出周期，检查温度条件。
2. 校验全部位置或连续运动保护终点、积分列、采样周期和数据量。
3. 定位扫描起点，检查 READY、实际位置允差和停稳。
4. 清空本次显示缓冲区并冻结计划；已有文件不删除。

初始化会实际移动电机，按钮旁有提示。完成后“开始扫描”才可用。扫描参数或相机参数变化、独立运动、独立采集、制冷 / 标定变更、重新连接或停止后均需重新初始化。一次初始化只用于一次扫描。

## 6. 点扫描

设置起点、步长、点数和每点停稳时间。点数包含起点，终点为 `起点+(点数−1)×步长`，负步长表示反向。

每点执行绝对定位，连续复核 READY 和实际位置允差，等待停稳，再触发相机。每帧曝光前后都检查位置；全部帧读出并保存、平均光谱提交后才定位下一点。记录位置与相机输出信号，并同时保留完整逐点光谱。

## 7. 连续扫描

设置起点、带符号的角速度（°/s）、采样周期、点数和预运行时间。电机只收到一次指向保护终点的 PA 命令，保持连续运动，按计划周期读取相机数据；采样之间不执行定位或 ST。采满指定点数后主动停止。

保护终点自动按速度、预运行、采样时长、实际曝光 / 读出与通信预算及停止余量计算，并在初始化时检查行程。它是覆盖采集时间的运动目标，不是最后一个采样点的承诺位置。预运行用于避开刚启动的部分过程，不代表已经验证电机达到恒速。

相机曝光和图像读出需要时间，且串口位置与 CCD 之间没有硬件同步。每帧保存曝光前和读出后的位置、主机时刻及 SDK 调用时刻，在两次位置之间对曝光中点做线性插值，作为记录的估计位置；多帧时取各帧估计位置的平均。位置跨度和模型标记同时写入 CSV。

**这不是编码器锁存位置或严格硬件触发同步。** 加减速、通信延迟、长曝光和多帧平均会扩大位置对应的不确定性。需要更严格的位置与信号对应时，使用点扫描，或另行设计经硬件支持的触发同步。图像采样不会自动生成空间上严格等间隔的数据。

周期必须容纳实际曝光 / 读出、通信和写盘预算；过短会在初始化时拒绝。运行中记录计划时刻、实际开始时刻和延迟；超过一个完整周期时终止，而不是无提示地跳点。电机提前停止或退出 MOVING 时终止，并保留已写入的原始帧。正常结束 / 中止后会尝试恢复原电机速度，失败时在日志中报告。

## 8. 波长标定

没有实测标定时使用角度扫描。要用波长坐标，导入经验证的 `λ(θ)=a0+a1θ+a2θ²+a3θ³` JSON，系数按低次至高次，支持一次到三次，单位 deg / nm。需提供有效角度范围，函数在范围内严格单调，禁止外推。

提供空白真实模板和仅模拟用模板。模拟系数禁止用于真实电机。点扫描按设定波长步长反解角度；连续扫描起点可用波长输入，但速度始终为角速度，实际波长位置依标定和测量 / 估计角度计算，不承诺等波长间隔。

该标定只定义选定参考像素的中心波长，不代替 CCD 的逐像素 `λ(θ,p)` 标定。SDK 也不会自动知道自建光栅机构的角度—波长关系。本版不自动拼接光谱或拟合真实标定。

## 9. 数据文件与中断

默认路径 `%LOCALAPPDATA%\Specreation\VUVScan\scans`，也可填写输出目录。每次采集建立独立的时间 / 项目文件夹。

| 文件 | 内容 |
| --- | --- |
| manifest.json | 设备来源、版本、计划、实际参数、标定、完成点数和状态 |
| scan_points.csv | 位置、前后位置、位置跨度及模型、中心波长、信号、温度、曝光和时间 |
| spectra.csv | 每点一行的完整平均光谱 |
| raw/*.npy | 每帧 int32 原始 SDK 数组，NumPy 可直接读取 |
| pixel_axis.npy | 原始探测器列中心坐标 |
| events.jsonl | 定位、到位、曝光、位置括定、原始帧保存和逐点提交日志 |

CSV 使用 UTF-8 BOM，可导入 Excel / Origin。时间戳用带时区 UTC，界面日志转换为电脑本地时间。连续扫描 actual_deg 为软件曝光中点估计，camera 模式未连电机时为空。

“全部停止”会请求终止曝光和电机 ST，并取消后续动作；已提交点不丢弃，中断点已写入原始帧保留。通信失败时仍应直接检查硬件，软件停止不代替实体急停。断电后以 manifest.completed_points 作为完整点边界，CSV 尾部可能有未提交行；partial_point 标明未完成点，状态仍为 running 表示需核查。本版不自动续扫。

## 10. 验证边界与维护

程序已在 Linux 构建环境用模拟设备、协议 / SDK 桩及 Chromium 测试。Windows 单文件 EXE 为交叉编译结果；本环境没有真实转台、相机和 Windows 驱动，尚未在 Windows 实机和实际设备上联机验证。首次真实运行应小行程、少点数、充分停稳，核对方向、角度单位、相机模式、数据格式和连续采样时序。

日志在 `%LOCALAPPDATA%\Specreation\VUVScan`，运行环境缓存位于其 runtime-cache。重复启动打开已有实例。缓存损坏会另建目录修复，不覆盖正在使用的 DLL，不删除测量数据。卸载前安全退出，删除 EXE 后数据仍保留。
