# 2.0.0 功能与验证记录

| 用户需求 | 实现 |
| --- | --- |
| 电机连接 / 断开、相机连接 / 断开 | 两套独立接口和按钮，允许只连一台设备 |
| 电机独立运动 | 绝对、相对正反向、速度设置、归零、停止，不依赖相机 |
| 相机参数设置与读取 | 曝光、平均帧数、读取模式、ROI/bin、速度 / 增益、快门、制冷；独立采集与 CSV 导出 |
| 扫描初始化 | 设备 / 参数 / 范围 / 周期预检，配置相机，定位并停稳起点，清空显示，冻结计划 |
| 点扫描 | 每点运动 → 到位 → 停稳 → 采集 → 保存，设置步长和点数 |
| 连续扫描 | 一次 PA 连续运动，按周期采集，设置速度 / 周期 / 点数，采满后 ST |
| 位置与强度记录 | CSV 保存积分信号及位置，另存完整光谱和每帧原始数据 |
| 软件名称 | 创谱科技-VUV质谱波长扫描软件 |
| 单机 EXE | Windows x64 单文件，自带 Python / NumPy / pyserial，本地浏览器界面 |
| 图标 | 电机与光谱曲线结合，嵌入 EXE 与界面 |

已通过 62 项 Python 自动化测试，覆盖输入校验、ROI、标定、独立连接与断开、真实串口协议桩、SDK2 Win64 ABI、初始化失效、两种扫描、连续运动不逐点停止、前后位置括定、周期超限、运动提前结束、停止与原速度恢复、磁盘故障、原始帧保留、冷相机生命周期、HTTP 认证与单实例锁。

Chromium 界面测试通过：仅连接电机的绝对 / 相对运动、仅连接相机的 ROI 采集、相机断开保留电机、浏览器 CSV 下载、点扫描 5 点 10 帧、连续扫描 8 点、连续曝光中停止、模拟波长扫描及连续扫描 31 点。页面没有 JavaScript 异常，全部请求仅在本机。

单文件封装另外验证内置负载、SHA256 / CRC、缓存复用及修复。编译器为 Go 1.27.4，图标资源工具 akavel/rsrc 0.10.2。运行时来自官方 Python 3.12.10 Windows x64 NuGet 与 NumPy 2.2.6 cp312 win_amd64 wheel，pyserial 3.5 随源码提供。

本环境没有 Windows 和真实设备。自动化测试不等于实际控制器、SDK 安装版本、机械停止、准确度或同步精度已经验证。连续位置属于软件曝光中点估计，非硬件同步；实际联机需厂家驱动及 Andor SDK2。
